Frequently Asked Questions

Answers to common questions about ID replacement.

How do I request a replacement ID?

Open Request ID, complete your student information, select a reason, and submit the form. Save your tracking reference.

How much does a replacement ID cost?

Please confirm the current replacement fee with the school's Registrar or Cashier. Any amount shown in this prototype should be verified with the school.

How long does processing take?

Processing time depends on school verification and printing. Contact the Registrar for the current expected timeframe.

How can I check my request status?

Open Track, enter your tracking reference, and select Search. The result shows the status recorded in the demo.

Can I upload a photo of my damaged ID?

You can select a supported photo or PDF in this demo. Actual file storage and secure submission require a backend server.
